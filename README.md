# Digit_Project
Machine Learning Web Application
قمنا بهذا المشروع  ببناء نظام للتعرف على الأرقام المكتوبة بخط اليد بين (0-9) باستخدام تقنيات تعلم الآلة كما اعتمدنا على مجموعة البيانات العالمية MNIST والتي تحتوي على 70,000 صورة
خطوات التنفيذ والتدريب على الشكل التالي:
قمنا بتصميم نموذج شبكة عصبية باستخدام لغة بايثون ومكتبة TensorFlow في بيئة Google Colab تم تدريب النموذج لمدة 5 دورات وحقق دقة تجاوزت 99% على بيانات الاختبار.
